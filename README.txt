NEXORA ESPORTS WEBSITE — MOBILE STARTER

Included:
- index.html: complete one-page responsive website
- style.css: styling and mobile layout
- script.js: menu, tournament interest form demo

OPEN ON ANDROID:
1. Download and extract nexora_esports_website.zip.
2. Open the extracted folder in Acode (or another code editor).
3. Open index.html and use Preview / Open in browser.
4. To change the brand, search for "NEXORA" in index.html and replace it with your chosen name.
5. Edit colors near the top of style.css in the :root section.

IMPORTANT:
- This is a front-end starter/prototype, not a complete live tournament platform.
- The interest form stores entries only in the visitor's own browser using localStorage. It does NOT send registrations to you.
- There is no real login, secure admin dashboard, database, payment integration, or prize handling yet.
- Before launch, connect a backend/database, add server-side validation and admin authentication, publish clear tournament rules/privacy terms, and test payment eligibility and legal requirements.
- Use your own original logo, artwork and text. Do not copy another site's protected branding or assets.
