NEXORA FREE FIRE - BATTLE ROYALE SOLO VERSION

Upload these three files to the ROOT of your GitHub repository, replacing the old versions:
- index.html
- style.css
- script.js

Keep filenames exactly lowercase. Commit changes; GitHub Pages will redeploy automatically.

This is a front-end demo. The registration form saves data only in the visitor's own browser and does not send it to the organizer. Real registrations require a secure backend/database. Tournament date, entry fee and prize are placeholders. This is an independent community concept and is not affiliated with or endorsed by Garena.
